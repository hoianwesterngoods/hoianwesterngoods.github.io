It cannot reach your Telegram account, and you can kill it in BotFather with /revoke at any time. Use a bot made only for this shop.

      How do I make a bot?
      1. In Telegram, search for @BotFather and open it.
      2. Send /newbot, then give it a name and a username ending in bot.
      3. It replies with a token like 1234567890:AA... — paste that above.
      4. Open your new bot and press Start, so it is allowed to message you.
      5. Come back here, press Find my chat, then Send a test message.

      Connection

      Where this page publishes to. All of it stays on this device.

      The token is stored in this browser and sent only to GitHub. Claude never sees it.

      Where do I get an access token?
      1. On github.com, click your picture (top right) → Settings.
      2. Scroll to the very bottom of the left-hand menu → Developer settings.
      3. Personal access tokens → Fine-grained tokens → Generate new token.
      4. Token name: shop. Expiration: choose No expiration.
      5. Repository access: Only select repositories, then pick your shop repository.
      6. Permissions → Repository permissions → Contents: change to Read and write.
      7. Press Generate token, copy what it shows you, and paste it above.
